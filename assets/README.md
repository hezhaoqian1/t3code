# Brand icons

`fd` is the only active runtime and product icon family. The approved tracked assets are:

- `fd/fangde-ai-1024.png` for macOS, Linux, and development desktop icons
- `fd/fangde-ai.ico` for Windows and web ICO output
- `fd/fangde-ai-16.png` and `fd/fangde-ai-32.png` for web favicons
- `fd/fangde-ai-180.png` for the web Apple touch icon and workspace icon

Build and development scripts copy these files to their platform-specific output locations. Development, nightly, and production builds intentionally use the same FD artwork.

There is no repository icon generator because the approved FD source artwork is not stored here. Do not derive product icons from retired artwork. Regeneration or replacement requires approved FD source artwork and review of every tracked bitmap and ICO output.
