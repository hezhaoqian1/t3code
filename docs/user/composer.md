# 桌面端输入框

## AI 工作时继续发送

AI 正在执行任务时，可以继续在输入框里输入。按回车不会打断当前任务，消息会进入输入框上方的“排队中”列表，当前任务结束后按顺序自动发送。

需要立即调整方向时，点击该消息右侧的“引导”。消息会马上插入当前任务，AI 在完成手头这一步（例如正在执行的命令或正在生成的这段回复）后读取它，并在同一个任务里按新要求继续，不需要先停止。想彻底放弃当前做法，可以点击停止按钮；停止后排队消息会作为新消息继续发送。

点击消息文字或铅笔图标可以修改内容，Enter 保存，Shift+Enter 换行，Esc 取消。正在编辑的消息不会被自动发送。垃圾桶图标删除这条消息。

以下情况暂时不能引导，列表顶部会说明原因：

- AI 正在等待授权或回答问题：请先处理授权请求或问题。
- 正在处理附件：附件处理完成、任务开始运行后即可引导。
- 本地服务正在连接。

带附件的消息不能排队，请等待当前任务完成后再发送。引导失败时，消息会留在列表中并显示原因，可以点击“重试”。
