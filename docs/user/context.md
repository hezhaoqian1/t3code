# 桌面端上下文

## 本次改进

FD AI 原先就会保存同一任务的上下文。本次修复的是切换模型、切换 FD Skill 和重启恢复时可能接不上原上下文的问题，并增加手动压缩。它不是永久记忆，也不代表每个模型都已启用官方最大窗口。

这项改进需要安装包含该变更的桌面客户端；仅更新服务器不会升级已有客户端的上下文管理。

同一任务中的后续消息会继续使用已有上下文。重新打开任务时，应用恢复本地保存的模型会话。聊天记录可以完整显示，但模型实际使用的较早内容可能已经被压缩成摘要。

## 压缩上下文

点击输入框旁的上下文指示器，再点击“压缩上下文”，或单独发送 `/compact`。压缩前请等待当前回复完成，清空草稿及附件。选中的托管 FD Skill 会保留，压缩的是该 Skill 的上下文。

完成后会显示“上下文已压缩”，随后可以继续提问。压缩期间可以停止；超时后需要停止并重新启动会话再继续。压缩失败不会删除聊天记录。

压缩保留的是摘要，并非所有原始细节。若模型忘记重要要求，可以再次说明，或重新提供相关图片、文件。

## 切换与恢复

在当前 FD 模型之间切换会继续使用同一任务上下文。每个托管 FD Skill 版本保存独立上下文；切换回来时恢复此前的内容。新选中的 Skill 不会自动继承另一个 Skill 的对话。

旧版没有 Skill 归属标识的会话作为普通任务上下文恢复。恢复记录损坏，或原模型会话已不存在时，应用自动使用新上下文继续，不要求手动修复，已有聊天记录仍保留。此时模型不再拥有旧上下文，需要重新说明必要背景。

网络超时、登录过期等临时故障会保留原上下文，待网络恢复或重新登录后重试。

## 查看用量

指示器显示当前上下文用量与运行时窗口。“累计处理”包含历次请求，不能当作当前上下文大小。运行时窗口可能小于模型厂商宣传的最大值，不同模型压缩后保留细节的能力也有区别。
