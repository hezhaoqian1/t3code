# 模型列表与下架提示

每个新任务都默认使用 Flash，无论是打开应用、点“新建任务”，还是在空间里开始新任务；也不会沿用正在查看的任务所选的模型。已有任务保留各自选择的模型，可随时在输入框右侧切换。

桌面端登录后只显示后台为当前账号提供的模型，并每 30 秒自动刷新。管理员下架模型后，无需重新登录，模型会从选择列表消失。

旧任务使用的模型不可用时，输入框提示“当前模型已不可用，请切换 Flash 重试”。在输入框右侧重新选择 Flash 后，可继续原任务；原有消息和待发送内容保留。应用不会自动替你切换模型。

如果后台没有提供任何模型，应用提示“暂无可用模型，请刷新模型列表或联系管理员”。网络暂时异常时会保留当前账号最后一次成功获取的列表；切换账号或退出登录会清除这份缓存。
