# 桌面端文件分析

桌面端可以在普通任务或选中 FD Skill 后上传文件，让 Agent 结合问题分析附件。选中 FD Skill 后，可以将文件和问题一起发送，无需先在普通对话中解析并等待回答。文件只用于当前任务，不会自动进入知识库、向量库或企业文件库；聊天历史保留文件名和附件元数据，不保留原始文件正文。

FD Skill 附件使用与普通任务相同的格式、大小和模型视觉能力限制。附件解析期间点击停止会取消本次处理；再次分析时需要重新附上文件。切换 FD Skill 不会自动携带其他 Skill 或普通对话的模型上下文。

## 支持格式

- PDF：按页提取文字，表格按行还原（同一行的各列用“|”分隔），并标出每页是文字页、含图表的页还是扫描页。详见下方“长 PDF 和图表”。
- PPTX：提取幻灯片文字、备注和表格内容，并保留幻灯片来源。
- DOCX：提取段落、标题和表格内容。
- XLS、XLSX、XLSM、XLSB、ODS：按工作表读取单元格值，保留工作表来源，不执行宏。详见下方“大表格”。
- CSV、TSV、TXT、MD、JSON、JSONL、XML、YAML、YML、LOG：读取 UTF-8 或带 BOM 的 UTF-16 文本。
- HTML、HTM、RTF、EPUB：提取可读正文。
- ODT、ODP：提取开放文档的正文或幻灯片内容。
- 旧版 DOC、PPT：需要本机安装 LibreOffice，由独立临时配置转换后读取；未安装时请另存为 DOCX/PPTX。
- PNG、JPG、WebP、GIF：由当前所选模型的视觉能力决定处理方式。支持原生视觉的模型会接收原始图片；不支持的外部模型会明确提示切换模型。仅 FD 自有模型可按其授权策略使用视觉预处理器，预处理结果作为有上限的不可信观察证据提供给主 Agent。

单个文档最大 25 MB，单次最多 8 个原始附件。单个 PDF 最多 500 页。长图会按阅读顺序切成有少量重叠的清晰分段；需要识别的页面或分段越多，耗时和模型用量越高。回答引用“第 X 页”“第 X 张幻灯片”或“工作表 X”时，以解析到的内容为准。

## 大表格

一次上传几张几千行的明细表也可以直接发送，不会再提示“附件与问题的总文本超过本轮容量”：

- 每个文件都会有一部分内容放入对话：表头和前面若干行（按整行截取），并注明全表共多少行、放入了多少行。多个附件时按文件平均分配，不会只放第一个文件。
- 每个工作表的全部行（最多 20 万行）会另存为一份完整的 CSV。需要统计、筛选、分组、去重或核对全表时，AI 会用命令读取这份 CSV 计算，而不是只凭放入对话的前几行推断；在“需要确认”权限模式下，这一步会先请你批准。
- AI 也可以直接按行号读取任意行（每次最多 500 行），界面上会显示“读取表格行”。
- 回答涉及全表结论时，AI 会说明计算范围。

## 长文档和一次发多个附件

Word、PPT、文本等长文档同样不会因为太长而报错：

- 对话里放入文档的开头部分，并注明放到了第几行、全文共多少行；PPT 按整张幻灯片放入，并列出没有放入的幻灯片。
- AI 需要后面的内容时，会按行号继续读取（每次最多 1000 行），或在全文中按关键词查找后再读上下文，界面上会显示“读取文档内容”。
- 粘贴的大段文字（自动折叠为“粘贴内容.txt”）也可以这样继续读取。
- 一次发多个附件时，粘贴内容、图片识别结果和各个文件的文字按比例分配本轮篇幅，不会因为其中一个特别大而让其他文件一点都放不进去。

只有直接输入在输入框里的文字本身超过约 20 万字节时，才会提示把长文本保存为文件作为附件发送。

## 长 PDF 和图表

上传 PDF 后，AI 会先拿到全部页面的文字，不必等每一页都“看”一遍：

- 文字页（包括只有页眉 logo 的页面）直接按文字阅读，几秒内就能开始回答。
- 含图表或图片的页，文字照常提供；问题涉及图中的数值、曲线或图里的表格时，AI 会自己打开相关的一两页查看，界面上会显示一次“查看 PDF 页面”的工具调用。
- 扫描页（没有文字层）在发送前就会识别，最多 40 页；更多的扫描页由 AI 需要时再查看。
- 文字特别多的 PDF（例如几百页）会先放入前面的页面和其余页面的目录，AI 需要时按页继续读取，不会因为太长而报错。
- 某一页识别失败（例如网络波动）时会自动重试；仍失败的页会在回答里注明未读到，其他页面照常使用。

支持原生视觉的模型（DeepSeek V4.1 Flash、Qwen 3.8、Kimi K3）查看页面时直接看到页面图片，读图表时可以反复对照。DeepSeek V4 Pro、GLM 5.2 等文字模型查看 PDF 页面时，使用授权的 DeepSeek Flash 视觉预处理服务：先给出整页识别结果，需要某个具体读数（例如曲线最高点）时会把这一页分成上下两半放大，再针对这个读数识别一次。整页识别结果会记住，同一任务里再次问到时不会重复识别。

AI 只通过上述工具读取附件，不会在你的电脑上搜索文件或用脚本处理附件。

PDF 里印刷的页码（例如页脚的“第 19 页”）可能和 PDF 的页序不同。提问时按印刷页码说就可以，AI 会对照核实；回答中会注明所依据的页。

## 使用方式

在桌面端输入框的“添加内容和能力”菜单中选择“添加文件”，也可以把文件拖入输入框或粘贴图片。图片会按当前模型的视觉能力路由；文档显示“待解析”时会随本轮消息发送。解析失败、格式不支持或文件损坏时，先移除该文件，仍可继续发送纯文本问题。

## 企业 Skill 边界

FD Skill 仍由企业运行时负责权限、数据工具和审计。桌面端只在本地保留员工可见的提问和最终回答；推理过程、工具参数与结果、审计标识、策略和凭据不会进入本地聊天历史。FD Skill 任务可以附带图片和文档：图片先经过服务端视觉预处理，结果以不可信证据注入本轮上下文；文档先由服务端解析为有界的页、幻灯片或工作表文本，再作为不可信内容注入本轮上下文。附件内容不能改变工具权限、Skill 权限或审计边界，且仍受格式、大小、数量、路径和二进制校验限制。

## 已知限制

- DOCX/PPTX/ODF 内的图表、SmartArt、嵌入图片不会自动还原为完整视觉布局；需要视觉理解时请导出 PDF，或同时上传图片并选择支持视觉的模型。
- 目前不解析 ZIP/RAR 等压缩包、音频、视频、CAD、PSD 和邮件容器。请先解压、转录，或导出 PDF、图片、文本及现代 Office 格式。
- HEIC/HEIF、TIFF、BMP、SVG 暂未接入图片上传，请先导出 PNG/JPEG。带宏的 Word/PPT、WPS 专有格式、Pages/Numbers/Keynote 请导出 DOCX/XLSX/PPTX 或 PDF。
- DeepSeek V4.1 Flash（模型 ID `deepseek-flash`）、Qwen 3.8 Max/Flash 和 Kimi K3 支持原生图片输入。DeepSeek V4 Pro 与 GLM 5.2 当前是文字路线；它们查看 PDF 页面时会使用 FD 视觉预处理，独立图片会明确提示切换视觉模型，不会静默把普通图片交给另一个模型。
- 图表和扫描页的识别可能出错，重要数值应对照原文核实。PDF 中用特殊字体绘制的公式可能显示为乱码，需要时请让 AI 查看该页画面。
- 表格每个工作表最多读取 20 万行，超出时会附带截取说明。旧版 DOC/PPT 转换需本机标准路径下的 LibreOffice，转换超时或失败会明确提示。
- 每轮放入对话的附件文字、识别结果和问题合计约 20 万 UTF-8 字节（约 6 万汉字）。超出部分留给 AI 按需读取：PDF 按页，表格按行或用完整 CSV 计算，Word、PPT、文本按行或关键词；不会因为附件太长而整轮失败。
- 图片上传受单张 10 MB、单次最多 8 个原始附件限制。长图和 PDF 衍生页面分批处理，总体积最多 48 MiB，单图最多 6400 万像素。超限或模型未获授权时会明确提示失败。
- 模型选择框会标示各模型的视觉能力。当前模型不支持视觉时，图片附件会被拒绝，不会静默改由其他模型识别。

## 上传与发送

添加附件后，文件会立即在后台上传到本机的方德 AI 服务，文件卡片上显示上传进度，完成后显示“已就绪”；发送消息时只需传递文件引用，大文件发送不会让界面卡顿。上传失败时卡片会提示并提供“重试”，即使不重试，发送时也会自动改为直接附带文件，不影响消息发送。移除附件或 24 小时内没有发送的上传会被自动清理。
