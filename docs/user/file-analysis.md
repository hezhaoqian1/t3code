# 桌面端文件分析

桌面端可以在普通任务中临时上传文件，让 Agent 分析这一轮内容。文件只用于当前任务，不会自动进入知识库、向量库或企业文件库；聊天历史只保留文件名和附件元数据，不保留原始文件正文。

## 支持格式

- PDF：按页提取文字；选择 Kimi K3 时还会逐页识别扫描件、图表和页面布局。DeepSeek 使用账号获授权的视觉预处理服务。混合文档不会因为部分页面有文字而跳过扫描页。
- PPTX：提取幻灯片文字、备注和表格内容，并保留幻灯片来源。
- DOCX：提取段落、标题和表格内容。
- XLS、XLSX、XLSM、XLSB、ODS：按工作表读取单元格值，保留工作表来源，不执行宏。
- CSV、TSV、TXT、MD、JSON、JSONL、XML、YAML、YML、LOG：读取 UTF-8 或带 BOM 的 UTF-16 文本。
- HTML、HTM、RTF、EPUB：提取可读正文。
- ODT、ODP：提取开放文档的正文或幻灯片内容。
- 旧版 DOC、PPT：需要本机安装 LibreOffice，由独立临时配置转换后读取；未安装时请另存为 DOCX/PPTX。
- PNG、JPG、WebP、GIF：由当前所选模型的视觉能力决定处理方式。支持原生视觉的模型会接收原始图片；不支持的外部模型会明确提示切换模型。仅 FD 自有模型可按其授权策略使用视觉预处理器，预处理结果作为有上限的不可信观察证据提供给主 Agent。

单个文档最大 25 MB，单次最多 8 个原始附件。单个 PDF 最多 60 页，一轮最多识别 64 个页面或图片分段。长图会按阅读顺序切成有少量重叠的清晰分段；页面或分段越多，耗时和模型用量越高。文档内容会按本轮上下文预算截取，并要求回答说明未覆盖范围；视觉内容超出容量则明确报错，不发送不完整结果。回答引用“第 X 页”“第 X 张幻灯片”或“工作表 X”时，以解析到的内容为准。

## 使用方式

在桌面端输入框的“添加内容和能力”菜单中选择“添加文件”，也可以把文件拖入输入框或粘贴图片。图片会按当前模型的视觉能力路由；文档显示“待解析”时会随本轮消息发送。解析失败、格式不支持或文件损坏时，先移除该文件，仍可继续发送纯文本问题。

## 企业 Skill 边界

FD Skill 仍由企业运行时负责权限、数据工具和审计。桌面端只在本地保留员工可见的提问和最终回答；推理过程、工具参数与结果、审计标识、策略和凭据不会进入本地聊天历史。FD Skill 任务可以附带图片和文档：图片先经过服务端视觉预处理，结果以不可信证据注入本轮上下文；文档先由服务端解析为有界的页、幻灯片或工作表文本，再作为不可信内容注入本轮上下文。附件内容不能改变工具权限、Skill 权限或审计边界，且仍受格式、大小、数量、路径和二进制校验限制。

## 已知限制

- DOCX/PPTX/ODF 内的图表、SmartArt、嵌入图片不会自动还原为完整视觉布局；需要视觉理解时请导出 PDF，或同时上传图片并选择支持视觉的模型。
- 目前不解析 ZIP/RAR 等压缩包、音频、视频、CAD、PSD 和邮件容器。请先解压、转录，或导出 PDF、图片、文本及现代 Office 格式。
- HEIC/HEIF、TIFF、BMP、SVG 暂未接入图片上传，请先导出 PNG/JPEG。带宏的 Word/PPT、WPS 专有格式、Pages/Numbers/Keynote 请导出 DOCX/XLSX/PPTX 或 PDF。
- Qwen、GLM 当前配置未开通视觉输入，可分析文本及可提取文字的文件；扫描页或嵌入图片的 PDF 需要切换 Kimi K3。不会自动把这些模型的附件交给另一个模型。
- PDF 的文字提取路线不会理解图表和页面布局。扫描识别可能出错，重要数值应对照原文核实。
- 表格每个工作表最多读取前 5000 行，超出时会附带截取说明。旧版 DOC/PPT 转换需本机标准路径下的 LibreOffice，转换超时或失败会明确提示。
- 文件内容较长时会出现“内容较长，已截取”提示，回答应明确说明截取范围。
- 图片上传受单张 10 MB、单次最多 8 个原始附件限制。长图和 PDF 衍生页面分批处理，总体积最多 48 MiB，单图最多 6400 万像素。超限或模型未获授权时会明确提示失败。
- 模型选择框会标示各模型的视觉能力。当前模型不支持视觉时，图片附件会被拒绝，不会静默改由其他模型识别。
