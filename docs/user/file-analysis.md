# 桌面端文件分析

桌面端可以在普通任务中临时上传文件，让 Agent 分析这一轮内容。文件只用于当前任务，不会自动进入知识库、向量库或企业文件库；聊天历史只保留文件名和附件元数据，不保留原始文件正文。

## 支持格式

- PDF：提取有文字的页面内容；扫描版 PDF 目前提示未启用 OCR。
- PPTX：提取幻灯片文字、备注和表格内容，并保留幻灯片来源。
- DOCX：提取段落、标题和表格内容。
- XLSX、CSV：按工作表或表格行读取内容。
- TXT、MD、JSON、XML、HTML：按 UTF-8 文本读取。
- PNG、JPG、WebP、GIF：继续使用桌面端原有图片输入能力。

单个文档最大 25 MB，单个任务最多 8 个附件。文档内容会按本轮上下文预算截取；回答引用“第 X 页”“第 X 张幻灯片”或“工作表 X”时，以解析到的内容为准。

## 使用方式

在桌面端输入框的“添加内容和能力”菜单中选择“添加文件”，也可以把文件拖入输入框或粘贴图片。文件显示“待解析”时会随本轮消息发送。解析失败、格式不支持或文件损坏时，先移除该文件，仍可继续发送纯文本问题。

## 企业 Skill 边界

本版本的 FD Skill 仍由企业运行时负责权限、数据工具和审计。为避免本地运行时或历史缓存接触敏感企业数据，FD Skill 任务暂不接受本地文档附件；需要分析企业文件时，应使用已授权的企业数据工具或等待后续的企业文件策略版本。

## 已知限制

- 不支持旧版 `.ppt` 和旧版二进制 `.xls`，请另存为 PPTX/XLSX。
- 图表、SmartArt、嵌入图片不会自动还原为完整视觉布局；需要视觉理解时请同时上传图片或截图。
- 文件内容较长时会出现“内容较长，已截取”提示，回答应明确说明截取范围。
