# 任务与空间

方德 AI 里有两种开始工作的方式：直接新建**任务**，或在左侧**空间**里打开一个自己的文件夹。两者里 AI 的能力完全相同，都能读写文件、运行命令和脚本、生成网页和报告；区别只在文件放在哪里和界面显示什么。

|                    | 任务（左侧“任务”列表）                       | 空间（左侧“空间”列表）                         |
| ------------------ | -------------------------------------------- | ---------------------------------------------- |
| 文件放在哪里       | 每个任务自动新建一个文件夹                   | 你添加空间时选择的文件夹                       |
| 界面               | 办公模式：顶部只有新对话、任务名、打开文件夹 | 开发模式：另外显示空间名称、Git 操作和分支信息 |
| 右侧面板与底部终端 | 可用：浏览器、文件、终端、变更、Agent        | 可用                                           |
| 默认模型           | Flash                                        | Flash                                          |

## 任务文件夹

新任务在**发出第一条消息时**，在 `~/FangdeAI/Tasks`（Windows 为 `C:\Users\<用户名>\FangdeAI\Tasks`）下创建自己的文件夹。只打开新任务页、不发送消息，不会创建文件夹。

文件夹名为“任务名*日期*时间”，时间为本机时间，精确到分钟：

```text
整理本周销售周报的三个要点_2026-11-11_16-01
写一个计算复利的-Python-脚本_2026-11-11_16-01
Summarize-three_2026-11-11_16-01
```

任务名取自第一条消息：

- 只取第一句话；第一个逗号前已经足够说明内容时，只取到逗号为止。
- 去掉“请帮我”“麻烦”“你好”等开头。
- 最多 20 个字；英文不会截断在单词中间。
- 只保留常用汉字、英文字母和数字，其余符号（空格、引号、`&`、`%`、表情等）换成 `-`，保证路径在 Windows、命令行和 AI 运行的各种工具里都能正常使用。
- 只有附件、没有文字时，名称为“新任务”或附件名；使用 FD Skill 查询企业数据的任务固定为 `FD-Skill-对话`，不会把查询内容写进文件夹名。
- 同一分钟内名称相同时，后面依次加 `_2`、`_3`。

左侧任务列表显示的是 AI 起的中文标题，几秒后才生成，所以会和文件夹名略有不同。任务进行时 AI 就在这个文件夹里工作，文件夹不会再改名；点任务顶部的“打开文件夹”可以直接打开它。

0.2.47 之前创建的任务保留原来按时间命名的文件夹（例如 `2026-11-11-15-20-46`），不受影响。

## 打开生成的文件

AI 生成的网页、PDF、图片会以文件标签显示，点击后在右侧内置浏览器中打开。也可以打开右侧面板，选择**文件**，在任务文件夹里点开任意文件。
