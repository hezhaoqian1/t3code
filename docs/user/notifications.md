# 任务通知

AI 处理任务时可以去做别的事。任务完成、失败，或者需要你回答问题、确认授权时，方德 AI 会提醒你：

- **应用在后台时**：弹出系统通知，并在任务栏图标（macOS 为程序坞图标）上显示待处理的任务数。点通知会直接打开对应任务；回到应用后数字自动清零。
- **应用在前台、但你正在看别的任务时**：右下角弹出应用内提示，点“打开任务”跳过去。正在看的任务不会重复提醒。
- **提示音**：可选。打开后，任务完成和需要处理时会播放不同的提示音。

在**设置 > 通用 > 通知**中调整：

- **任务通知**：关闭、仅系统通知（默认）、仅提示音、系统通知和提示音。
- **应用内提醒**：默认开启。
- **发送测试通知**：按当前设置发一条测试通知。没看到通知时，请在 Windows 的“设置 > 系统 > 通知”中允许方德 AI 发送通知；macOS 在“系统设置 > 通知”中开启。

应用打开之前就已经完成的任务不会补发通知；已归档的任务不会提醒。

正在运行的任务会在后台保持同步，切到它时立刻看到最新进展，不需要重新加载。
