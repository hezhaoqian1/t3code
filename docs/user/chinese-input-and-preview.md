# 中文输入与文件预览

使用中文输入法时，按回车确认候选词会继续停留在输入框。选词完成后，再按回车提交任务名称或设置。

输入 `￥` 也可以唤起技能选择。中文输入法无需先切换英文符号。

回答中的本地图片可以直接显示。宽表格支持横向滚动，HTML 页面按 UTF-8 显示中文，并在隔离环境中预览。

文件链接支持中文名称、空格和 Windows 路径。打开报告后，其中的相邻文件链接和图片按报告所在文件夹定位。右侧文件列表会显示 PDF、Word、Excel、PPT 等成果文件，展开文件夹时加载其内容；新生成的文件可以点击刷新查看。

文件预览会区分无法读取、文件夹、任务目录之外的链接和不支持的格式。文件尚未生成时，等待生成完成后点击“重新读取”。Word、Excel、PPT 等办公文档需要点击“用系统应用打开”，由电脑上的 Office 或 WPS 查看；HTML、PDF 可使用上方的浏览器预览按钮。

读取失败时会显示实际读取位置和任务文件夹。向管理员反馈时，请一并提供这两个路径，方便核对文件是否保存在正确位置。

`SKILL.md` 是技能说明。若链接指向 `userdata/codex-home/skills/.../SKILL.md` 却无法读取，请确认自己需要的是技能说明还是生成结果；查看生成结果时，让 AI 提供实际成果文件的链接，或从右侧文件列表选择。

FD 技能执行失败时，会尽可能区分原因：

- 模型限流：稍后在当前任务中继续。
- 模型服务额度不足：联系管理员检查额度，或切换可用模型。
- 上下文超限：压缩上下文，或新建任务继续。
- 连接中断或响应超时：稍后重试。

若仍无法完成，请向管理员提供任务名称和报错时间。
