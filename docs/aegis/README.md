# Aegis Design Workspace

This directory records reviewed FD AI product and architecture decisions before implementation.

- `baseline/` captures the current product and runtime boundary.
- `specs/` contains proposed or approved implementation specifications.
- `adr/` records durable architecture decisions after implementation proves them.
- `INDEX.md` lists the governed artifacts.

The shipped user and maintainer documentation remains under `docs/user/`, `docs/internals/`, and
`docs/operations/`. A specification in this directory is not proof that implementation is complete.
