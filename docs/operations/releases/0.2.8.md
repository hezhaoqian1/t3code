# FD AI Desktop 0.2.8 发布说明

## 交付范围

- 桌面端左下角显示当前员工姓名；没有 `displayName` 时回退到登录账号名。
- 点击员工姓名打开账号菜单，提供“用量统计”“设置”和“退出登录”。退出登录进行中时会
  禁用重复提交并显示进行中状态。
- Web 端继续使用用量统计、设置和退出登录三个独立的侧栏入口，不改变网页端布局或行为。

## 发布产物

仅发布内部未签名的两个平台：

- macOS Apple Silicon：DMG 与 updater ZIP
- Windows x64：NSIS EXE 与 blockmap

由 `.github/workflows/fd-desktop-release.yml` 以版本号 `0.2.8` 构建。不要发布 macOS Intel
或 Windows ARM64 产物。构建完成后，使用 FD Gateway 发布器执行清单、架构、哈希和原子激活
校验，再将 `latest.json`、`latest-mac.yml` 和 `latest.yml` 指向新版本。

## 验收

1. macOS Apple Silicon 和 Windows x64 均能显示当前员工姓名；空姓名账号显示用户名。
2. 点击姓名后，三个菜单项分别进入用量统计、设置并安全退出登录。
3. 退出登录请求进行中时，菜单项不可重复点击；失败时账号菜单仍可再次打开。
4. Web 端仍显示原有三个独立侧栏入口。
5. `latest.json` 的 `latestVersion` 为 `0.2.8`，两个平台下载地址和更新清单均返回成功。

Windows 真机更新和 macOS DMG 覆盖安装仍按
[`桌面端更新`](../../user/updating.md)执行；没有对应真机证据时，不声明该平台的安装流程已
完成验收。
