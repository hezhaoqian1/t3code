# 0.2.42：中文输入、预览与长任务错误提示改进

## 员工可见改动

- 中文输入法确认候选时，不再提前提交任务重命名或设置输入；技能入口识别 `￥` 等输入法货币符号。
- 宽表格可横向滚动，中文 HTML 预览使用 UTF-8，生成的本地图片可以在回答中展示。
- 修复 Windows、含空格的成果文件链接和报告内相邻文件链接；文件列表按需读取目录，显示被搜索索引过滤的 Office/PDF 文件。
- 文件读取失败显示中文原因、实际路径和重试入口，Office 文档提供“用系统应用打开”。
- HTML 预览隔离本地服务权限；内网链接不向公共图标服务发送主机名。
- 回答中的完整段落和列表项及时展示，文件保存期间关闭编辑器不再被旧内容覆盖。
- FD Skills 失败按限流、额度不足、上下文超限、超时和连接中断显示中文提示。
- GLM 等不支持图片的模型收到图片时，提示“请切换 Flash 后重试”。GLM 保持阿里百炼 `glm-5.2`。
- 改进后端启动探测、断开连接处理、协议缓冲和进程终止清理，减少空闲进程扫描。

## 验证与发布

本轮改动已通过相关定向测试、server/web 包级类型检查、桌面构建及隔离 Electron 中文输入、重命名、本地图片、HTML 预览实测。最后的图片提示调整通过 3 个测试文件、45 项测试。

按[发布手册](../release.md)从 `main` 构建 Windows x64 与 macOS arm64 安装包，再由 Gateway 发布器验证并原子切换更新源。发布前公开版本为 0.2.41。

网关瞬时限流重试为独立 PR #121，不随桌面安装包生效；本版本不宣称已经解决上游额度不足。
