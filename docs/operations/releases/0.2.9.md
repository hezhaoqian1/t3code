# FD AI Desktop 0.2.9 发布说明

## 交付范围

- 普通任务默认继续使用 `deepseek-v4-flash`，发送按钮左侧新增 `V4 Flash` / `V4 Pro` 模型选择。
- 同一任务中可以在 Flash 与 Pro 之间切换；桌面端会重建对应运行会话，不要求员工新建任务。
- 两个模型都继续通过 Codex App Server Agent 流程运行，支持本地文件、终端和普通 Skills。
- 飞书连接器支持清除旧身份并切换账号；员工取消授权时恢复“未启用”状态，不再误报红色错误。
- 飞书账号是否能选择公司组织仍由飞书企业租户授权决定，桌面端不保存或分发企业 App Secret。

本版本不新增图片视觉解析、OCR、第三方模型或 API Key 设置。FD Skill 与网页端企业 Agent
运行边界保持不变。

## 发布产物

仅发布内部未签名的两个平台：

- macOS Apple Silicon：DMG 与 updater ZIP
- Windows x64：NSIS EXE 与 blockmap

由 `.github/workflows/fd-desktop-release.yml` 以版本号 `0.2.9` 构建。不要发布 macOS Intel
或 Windows ARM64 产物。发布目录必须包含上述四个二进制文件、`latest-mac.yml`、`latest.yml`
和 `SHA256SUMS`，并通过 FD Gateway 发布器校验后原子切换公共 `latest`。

## 自动化验收

1. 模型授权只接受 `deepseek-v4-flash` 和 `deepseek-v4-pro`，Flash 保持默认。
2. Pro 与 Flash 的 Responses 请求均携带准确模型名，不静默回退。
3. 同一任务切换模型时重建 Provider 会话，历史任务仍保留。
4. 两个模型均完成真实文本响应和 Codex App Server 工具调用。
5. 飞书授权等待可取消、旧身份可清除、重新授权可验证，取消操作不显示失败通知。
6. Desktop、Web、Server 和 Contracts 类型检查、生产构建、Electron smoke 与 release smoke 通过。

## 真机验收

macOS Apple Silicon：

1. 安装 DMG 后启动应用，确认 `V4 Flash` / `V4 Pro` 选择器位于发送按钮左侧。
2. 同一任务先用 Pro、再切回 Flash，确认两次响应和本地工具调用均成功。
3. 在飞书授权等待中点击取消，确认页面回到“未启用”且没有红色错误通知。
4. 点击“切换账号”后确认重新进入设备授权流程；企业账号置灰时核对飞书租户应用授权。

Windows x64：

1. 完成与 macOS 相同的模型选择、同任务切换和飞书授权取消验收。
2. 从 `0.2.8` 检查更新，完成下载、重启安装，确认桌面和开始菜单快捷方式仍存在。

没有对应平台真机证据时，只声明该平台构建与自动化检查通过，不声明安装或更新流程已完成验收。
