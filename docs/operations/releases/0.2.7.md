# FD AI Desktop 0.2.7 发布说明

## 交付范围

- 主侧栏使用横向“新建任务”按钮；Logo 与任务搜索位于顶部，连接器位于新建任务下方，退出登录固定在底部。
- 已归纳任务不再显示在主侧栏，统一在**设置 > 已归纳任务**中查看和恢复。
- 工作空间选择器移动到输入框底部，位于 **FD Skills** 右侧；不再在新任务标题区重复显示。
- Agent 执行过程默认显示一行中文进度摘要，原始命令、工具调用和过程说明仍可展开查看。
- Codex App Server 图片输入改用已持久化文件的 `localImage` 路径，支持在普通任务中直接分析截图。
- 飞书授权支持取消等待、识别过期登录态和幂等断开，并显示飞书 CLI 返回的实际错误。
- 设置、工作空间导入/克隆、版本控制、主题与字体等本轮涉及界面完成中文化。
- Windows 标题栏保留可拖动空白区域，任务标题按钮不再覆盖整行。

## 发布产物

仅发布内部未签名的两个平台：

- macOS Apple Silicon：DMG 与 updater ZIP
- Windows x64：NSIS EXE 与 blockmap

构建由 `.github/workflows/fd-desktop-release.yml` 接收版本号 `0.2.7` 后生成。不要发布 macOS Intel 或 Windows ARM64 产物，也不要把 GitHub Actions artifact 直接当作官网更新源；必须继续使用 FD Gateway 的桌面发布器验证并原子激活。

## 真机验收

macOS Apple Silicon：

1. 主侧栏无“已归纳任务”区域，设置页可以恢复归纳任务。
2. 新建任务按钮、连接器、搜索、设置和退出登录位置正确。
3. 输入框底部依次可见添加、FD Skills、工作空间；窄窗口可横向滚动且不遮挡发送按钮。
4. 上传真实 PNG/JPEG 后，Agent 能读取图片内容。
5. 飞书授权等待中可以取消；过期登录态可以断开并重新扫码。
6. Agent 运行时默认只显示一行摘要，展开后仍能查看详细工具活动。
7. 使用新 DMG 覆盖安装后，应用图标、任务历史和设置保持正常。

Windows x64：

1. 在窗口顶部空白区域拖动窗口，标题和按钮区域仍可正常点击。
2. 完成与 macOS 相同的侧栏、图片、飞书和 Agent 摘要验收。
3. 从上一稳定版检查更新，完成下载和可见安装后重启应用。
4. 确认桌面与开始菜单快捷方式、应用图标和安装目录仍存在。

没有 Windows x64 真机证据时，只能声明 Windows 构建与自动化检查通过，不能声明拖动和更新流程已经真机验收。
