# 0.2.43：同步后台模型与下架提示

## 员工可见改动

- 桌面模型列表以当前账号的后台授权为准，每 30 秒刷新；下架模型不再显示。
- 旧任务所选模型下架时，提示“当前模型已不可用，请切换 Flash 重试”，保留原有消息和待发送内容。
- 仅剩 Flash 时仍可从已下架模型切换过来；后台模型列表为空时禁用发送并显示原因。
- 普通任务和 FD Skills 收到模型不可用错误时显示同一条中文提示。
- 修复内置 PPT 能力包摘要过期和 Windows 路径参与摘要计算的问题，保持两端校验一致，并继续拒绝内容被修改的包。
- 恢复办公任务顶部的“打开文件夹”；系统目录打开不再依赖编辑器命令探测，目录缺失或打开失败时显示中文提示。
- 新增 macOS Intel（x64）安装包和自动更新包，与 Apple 芯片版分别构建、校验和提供下载。

## 验证与发布

通过 71 项服务端测试、88 项前端测试、server/web 包级类型检查及改动文件静态检查。独立复审通过。

隔离 Windows Electron 验收通过六项场景：选择 Qwen Max、下架后自动刷新、阻止发送并保留草稿、只剩 Flash 时切换、空列表、重新上架后自动恢复。使用隔离模型目录，不修改生产渠道。

按[发布手册](../release.md)从已合并的 `main` 构建 Windows x64、macOS arm64 与 macOS Intel x64 安装包，验证后使用 Gateway 分片发布器上传并切换更新源。发布前公开版本为 0.2.42。macOS 原生归档验证由 CI 执行，本轮未做 Mac 真机升级验收。
