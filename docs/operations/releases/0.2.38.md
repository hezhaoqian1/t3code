# 0.2.38：FD Skill 附件

选中 FD Skill 后可将文件、图片和问题一起发送。附件引用保留在聊天历史和临时消息中，并进入现有附件解析流程；无需先在普通聊天中完成一次文件问答。

## 验证

- 普通聊天、FD Skill、本地 Skill 三种模式的附件保存、真实 TXT/XLSX/PDF/PNG 解析及取消重试对照测试通过。
- 真实生产登录、授权 Skill 目录读取通过。使用桌面端的原生 Codex App Server 和 Kimi K3，三种模式均从实际上传的 TXT 附件正确提取随机校验码，并在下一轮无附件追问中正确复述。测试仅使用合成数据；临时模型凭据和登录会话已撤销。
- 修正 PDF 旧测试的过时预期：完整文字页提取文字，扫描页渲染识别，保留原始页码和渲染像素校验。
- 前端相关测试 156 项通过。桌面界面的手动点击验收仍受浏览器控制工具认证错误阻塞。

## 行为边界

FD Skill 继续使用独立权限与模型会话上下文。文件格式、大小和模型视觉能力限制仍然生效。取消解析后需要重新附上文件，本版本未实现自动恢复附件。

## 发布

通过 `FD Desktop Internal Release` 从包含本次修复的 `main` 构建 Windows x64 与 macOS arm64 安装包。Actions 成功只代表产物就绪；正式更新还需使用 Gateway 发布器校验并切换下载服务的 `latest`，随后验证公开版本和更新清单。
