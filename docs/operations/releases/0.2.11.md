# FD AI Desktop 0.2.11 发布说明

状态：内部 unsigned 版本已激活。2026-08-21 已发布到
`https://ai-api.fdsure.com/downloads/desktop/latest`，线上 `latest` 指向 `0.2.11`，回滚目标为
`0.2.10`。

## 交付范围

- 合并 Desktop bounded local document analysis 功能（PR #10）。
- 修复 pnpm 11 对传递依赖 `tesseract.js` 的显式构建策略，保持 V1 不启用 OCR（PR #11）。
- 发布矩阵固定为 macOS Apple Silicon 的 DMG/ZIP 和 Windows x64 的 EXE/blockmap。

## 构建与发布证据

- GitHub Actions release run `32436046553`：macOS arm64、Windows x64 和 bundle 全部成功。
- Gateway 使用 16 MiB 分片上传、每片 SHA-256、重试和断点复用；远端整包组装后通过 `SHA256SUMS` 校验，再原子切换 `latest`。
- 服务器链接：`latest -> releases/0.2.11`，`previous -> releases/0.2.10`。
- 服务器 `sha256sum -c SHA256SUMS`：9 个发布文件全部 `OK`。
- 公网 `latest.json`、两个 updater manifest、安装包、blockmap 和稳定下载别名均返回 HTTP 200；Windows EXE 的 `Range: bytes=0-1023` 返回 HTTP 206。
- 公网 `latest.json.latestVersion` 为 `0.2.11`，Gateway `/api/status` 仍为健康状态，运行 SHA 未因桌面发布改变。

## 真机验收边界

本次完成了本地 bundle 校验、服务器哈希校验和公网下载/Range smoke。当前没有在本轮重复完成带真实员工凭据的模型回合，也没有声称 macOS/Windows 真机安装升级闭环已完成。unsigned 包首次安装可能触发 macOS Gatekeeper 或 Windows SmartScreen；正式签名、真机安装和可见升级仍是生产门禁。
