# FD AI Desktop 0.2.10 发布说明

状态：已激活。2026-08-17 已发布到 `https://ai-api.fdsure.com/downloads/desktop/latest`，线上版本为
`0.2.10`。源代码、两平台构建、Gateway 激活和公网文件验收均已完成。

## 交付范围

- 飞书连接状态提升为登录后的应用级共享状态；任务页和连接器页不再分别启动状态查询。
- 飞书 IPC 事件到达后，较早发起的状态读取不会再覆盖新的“已连接”状态。
- 首次同步期间明确显示“正在同步飞书连接状态”，不再先误报“未连接”。
- 连接器页面、任务输入菜单统一使用同一套连接判断：已启用、已授权且 Skills 已安装。
- 发送和停止按钮固定保留空间，模型选择器缩短为 96px，避免发送按钮被挤出输入框。
- 左下角员工入口改为与侧栏一致的行式样式，并保留“用量统计”“设置”“退出登录”。

本版本不改变 Flash/Pro 路由、FD Skills 风险边界、网页端企业 Agent 或企业权限体系。

## 官方依据

发布前已按官方资料核对实现，而不是从现有代码猜测：

- React `createContext`：Provider 放在共享消费者上层，消费者读取最近的 Provider 值。
- React `useEffect`：订阅 setup 返回对称 cleanup；依赖变化或卸载时先执行 cleanup。
- Electron `ipcRenderer`：在 preload 中包装 renderer 回调，不向页面暴露 event，并以同一个
  listener 调用 `removeListener`。
- 飞书官方 `@larksuite/cli 1.0.86` README 和内置 `--help`：确认本版本使用的五组命令及参数
  均受官方 CLI 支持。

具体官方链接和本地自检命令见[桌面端发布手册](../release.md#upstream-api-verification)。

## 自动化验收

1. 初始状态读取正常发布到共享 Provider。
2. 较新的 IPC 状态事件使旧查询结果失效。
3. Provider 卸载后，仍在途的读取结果不能再写入 UI。
4. `checking`、`connected`、`disconnected` 三种展示状态均有聚焦测试。
5. 飞书“已连接”必须同时满足启用、授权成功和 Skills 可用。
6. Web 聚焦测试、类型检查、定向 lint、生产构建和 `git diff --check` 全部通过。

## 真机验收

macOS Apple Silicon：

1. 打开任务输入菜单，确认飞书已连接时立即显示“已连接”。
2. 从任务页进入连接器页，确认不会先闪现“未连接”再刷新。
3. 确认发送按钮始终可见、模型框宽度正常、账号菜单三个入口可用。
4. 安装新 DMG 覆盖旧版本后，完成一次真实任务并复查上述 UI。

Windows x64：

1. 完成与 macOS 相同的连接状态和输入框验收。
2. 从 `0.2.9` 检查更新，完成下载、可见安装和重启。
3. 确认桌面图标、开始菜单快捷方式和员工任务数据均保留。

没有对应平台真机证据时，只声明该平台构建与自动化检查通过，不声明安装或更新流程已完成。
