# 0.2.39：排队消息可引导当前任务

AI 运行中按回车的消息继续进入排队列表；“立即发送”原先在运行中只会把消息移到队首，只有一条消息时没有任何效果。现在改为“引导”：消息立即作为同回合追加输入发给正在运行的 Codex App Server，AI 在当前步骤结束后读取并调整方向，不需要停止任务。

## 变更

- 排队列表改为输入框上方的紧凑卡片：每条消息带“引导 / 编辑 / 删除”，顶部显示数量与不可引导的原因（等待授权或回答、附件处理中、本地服务连接中）。
- 引导不读取输入框，正在输入的草稿和附件保持不变。
- 正在引导或正在编辑的消息不会被任务结束后的自动发送重复发出或以旧内容发出。
- 编辑排队消息时 Enter 保存，中文输入法选词的回车不会误保存。
- 去掉每次排队都弹出的提示，运行中输入框提示“回车加入排队”。

## 验证

- 前端：`sendQueueStore` 与排队列表组件测试、相关组件测试共 23 项通过；web 类型检查通过。
- 服务端未改动。运行中第二次 `thread.turn.start` 直接转发给 provider、不重启会话已有回归测试覆盖；FD 普通任务与 FD Skill 均经由 Codex App Server，运行中的 `turn/start` 由其作为同回合引导处理。
- 桌面端真实点击验收待安装包构建后进行。

## 行为边界

引导的生效时机由 Codex 决定：在当前工具调用或当前这段模型输出结束后读取，不会截断正在执行的命令。附件处理期间、等待授权或回答时不能引导。带附件的消息仍不能排队。
