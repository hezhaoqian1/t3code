# 0.2.40：排队与引导完善、更新不中断任务、Codex 0.159

本版本把“AI 工作时继续发送”做完整，修复 0.2.39 中排队消息无法引导、任务结束后不自动发送的问题（0.2.39 不对外发布），并吸收上游 t3code 适合企业员工使用的一批改进。桌面端内置的 Codex App Server 从 0.147.0 升级到 0.159.3。

## 排队与引导

- 修复：0.2.39 中“引导”按钮始终不可点、排队消息在任务结束后不发送（连接状态判断写反）。
- 排队消息保留发送时输入框里的全部内容：文字、图片和文件附件、终端内容、批注、所选模型、权限模式、计划模式和 Skill。附件在排队期间提前上传。
- 切换到别的任务后，排队消息仍会在原任务结束后自动发送；左侧任务列表显示时钟和待发送条数。
- 每条排队消息可“放回输入框”（连同附件）；点击停止会把所有排队消息放回输入框，不会在停止后自动发出。
- Ctrl+Shift+Enter 立即引导：输入框有内容时直接插入正在运行的任务，否则引导最早一条排队消息。
- 设置 → 通用 → 运行中发送消息：排队（默认）或立即引导。
- 发送失败的消息保留在列表中等待“重试”，不会循环重试；上一回合仍在收尾时自动稍后重试。

## 更新和重启不中断任务

- 应用更新、意外退出或任务进行中关闭应用后，12 小时内重新打开会自动从中断处继续任务，任务中显示“应用重启后已自动继续任务”。可在 设置 → 通用 → 重启后继续未完成的任务 中关闭；关闭后中断的任务会提示发送新消息继续，不再一直转圈。
- 更新确认框说明运行中的任务会在新版本启动后继续。

## 输入框与附件

- 粘贴超过 32 KB 的文字自动变成“粘贴内容.txt”附件，AI 按用户原话读取；附件上可“放回输入框”，Ctrl+Shift+V（macOS ⌘⇧V）直接粘贴为文字。
- 附件添加后立即在后台上传并显示进度，发送时只传引用；上传失败自动改为直接附带。
- 支持 iPhone HEIC/HEIF 照片（自动转 JPEG）；图片查看器支持缩放、拖动和键盘操作。
- 在空输入框按 ↑ / ↓ 调出之前发过的消息。

## 通知与任务列表

- 后台任务完成、需要授权或回答、失败时发送系统通知（可选提示音），Windows 任务栏 / macOS Dock 显示角标；设置中可选择通知方式并发送测试通知。
- 有未发送草稿的任务在任务列表中标出，可直接丢弃并撤销。
- 归纳、稍后提醒、取消置顶后可在提示中撤销，或按 Ctrl+Z。
- 消息时间按今天 / 昨天 / 日期显示；聊天区宽度可选舒适、较宽、铺满。
- 命令面板（Ctrl+K）新增“重启 AI 会话（加载新的 Skill 和连接器）”，新任务下为“重新加载 Skill 和连接器”；FD Skills 菜单可刷新。

## 验收中发现并修复

- 大段粘贴先被编辑器插入正文再变成附件：输入框改为在捕获阶段处理粘贴（与上游一致）。
- “放回输入框”后文字不出现：异步读取的文字改为同步提交，避免被编辑器的旧内容覆盖。
- 命令面板按显示的标题（如“重启 AI 会话”）搜不到命令；任务未加载完详情时不显示“重启 AI 会话”。
- 本地服务尚未连上时操作失败的提示是英文原始错误（如 “bird is not connected.”），改为“本地服务正在连接，请稍后再试。”。
- 自动化验收中约 1/10 的退出出现“服务已停止但窗口不关闭”：退出 5 秒仍未完成时主动关闭窗口，再 3 秒仍未退出则结束进程。

## 稳定性与性能

- 输入框打字延迟修复（修饰键状态不再每次按键全量读取）。
- 桌面端缓存编译后的 JavaScript，第二次起启动更快。
- 错误页可一键复制完整错误报告。
- Codex 0.159.3：重新生成协议绑定；回滚改用 thread/revert，线程历史按页读取。
