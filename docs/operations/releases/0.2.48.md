# 0.2.48：同一个任务里同时使用多个 FD Skill

## 员工可见改动

### FD Skills 多选

- 输入框下方的 **FD Skills** 菜单可以勾选多个 Skill（最多 4 个）。AI 在同一个任务里同时使用它们的数据和工具，例如同时选中「FD数据资源」和「宏观与市场数据」，把公司产品数据和宏观、指数、行情数据放在一起对比。
- 勾选时菜单保持打开，点「完成」、按 Esc 或点菜单以外的地方收起；再点一次已勾选的 Skill 取消它，「清除已选」一次取消全部。
- 菜单每行只显示 Skill 名称，不再显示简介，六个 Skill 一屏显示完；更多时列表在窗口内滚动。
- 按钮显示第一个 Skill 的名称和其余个数，例如「FD数据资源 +1」，鼠标停在上面可以看到全部名称。
- 每一种 Skill 组合有自己独立的上下文：它不继承其中任何一个 Skill 单独使用时的对话，增减 Skill 相当于换到另一段对话，换回原来的组合时恢复此前的内容。
- 管理员收回其中一个 Skill 的权限后，它会自动从已选中移除，其余 Skill 保持选中。

用法见[输入框](../../user/composer.md)和[上下文](../../user/context.md)。

### 新的 FD Skill：宏观与市场数据

随 Gateway 0.0.29.0 上线，无需升级应用即可在 FD Skills 中看到（已授权「FD数据资源」的访问组默认可用）。它查询公开的宏观经济指标、利率与债券收益率、指数、公募基金和行情数据，数据范围和限制见 Gateway 的运维说明。

## 实现

- 一轮对话携带的 Skill 由 `fdSkillVersionId`（编号最小的一个）和 `additionalFdSkillVersionIds`（其余）表示，旧版本记录的单 Skill 对话照常读取。
- 服务端为每个选中的 Skill 向 Gateway 取一份运行上下文并合并到同一个 Codex 会话：规则按 Skill 分段，同名工具只保留一份，每次工具调用按工具所属的 Skill 回到 Gateway 执行和审计。Gateway 协议不变。
- 执行上下文按 Skill 组合区分（`enterprise:<编号>+<编号>`），与单个 Skill 的上下文互不混用。
